Help every buyer find their project in two taps

The Vilamoura World hub lists 11 projects. On mobile, most visitors don't scroll and many open the first card. Here are four ways to filter by property type and bedrooms.

Try the Prototypes

Key facts are buried

Type and size sit inside long paragraphs, so projects are hard to compare.

The first card gets the clicks

Visitors who don't scroll never see the projects further down.

The wizard felt heavy

A multi-step quiz asks for effort before showing any projects.

Concept A · Recommended

Sentence filter

"I'm looking for a home to live in with 3+ bedrooms." Tap an underlined phrase to change it. The list updates straight away.

  • Fits the editorial tone of the site.
  • Projects stay on screen while filtering.
  • If nothing matches, it shows the closest projects.
  • Cards show type, bedrooms and one key selling point.
Concept B

Intent tiles and bedroom bar

Three tiles (Live here, Invest, Touristic) and a bedroom bar that stays in view while scrolling.

  • Closest to the current page, so the simplest to build.
  • Each tile shows how many projects match.
  • Cards add bedrooms, a highlight and a starting price.
Concept C

Category rows

Projects grouped into rows by property type, swiped sideways. There is no filter to open.

  • The first screen shows several projects per category.
  • The bedroom bar filters all rows.
  • "See all" opens the full category.
Concept D

Filter button and bottom sheet

A button at the bottom of the screen opens a panel with property type, bedrooms and a result count. Common on property portals.

  • Easy to reach with one hand.
  • Shows matching projects before applying.
  • Active filters show as removable tags.
